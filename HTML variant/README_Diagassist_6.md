# Diagassist 6

Откройте `Diagassist_6.html` в актуальном Edge или Chrome. Node.js, установка
программы и административные права не нужны. Для ИИ требуется интернет и
рабочий профиль провайдера с достаточным балансом.

1. Нажмите «Выбрать папку базы» и укажите папку на своей флешке.
2. База: `oncoassistant-patient-db.json`; предыдущая версия:
   `oncoassistant-patient-db.json.backup`. При новой сессии выберите эту же папку.
3. Для восстановления пациента откройте «База пациентов».
4. Настройте ИИ. Сохранение HTML с профилями создает персональную копию с
   открытыми API-ключами. Не публикуйте и не передавайте эту копию.
5. Перед извлечением флешки нажмите «Сохранить», дождитесь успеха, затем
   «Завершить сеанс» и закройте вкладку.

До выбора папки данные находятся только в памяти. Ошибка записи означает,
что сохранение не подтверждено. Не закрывайте вкладку, пока не сохраните
данные; при необходимости используйте экспорт JSON и явно выберите флешку
в диалоге браузера. Обычное скачивание может попасть в Downloads чужого ПК.

Предыдущие осмотры имеют отдельные поля полного текста и краткого резюме.
Полный текст используется ИИ; в отчет входит только краткая хронология.
Повторные исследования добавляйте отдельно с датами. Неизвестную дату
оставляйте пустой. Сравнение динамики выполняется ИИ, а не автоматически
вычисленным медицинским правилом.

Вкладка документов поддерживает до 10 вставленных текстовых документов;
загрузка файлов остается доступной. Проверяйте флаг «Использовать для ИИ».

Программа не записывает новые данные приложения в localStorage в portable
режиме, но не может гарантировать отсутствие следов ОС, истории браузера,
корпоративного мониторинга, буфера обмена и запросов у ИИ-провайдера.
База и HTML с профилями не зашифрованы. Любой человек с доступом к HTML может
скопировать код. Решения и назначения ИИ требуют проверки врачом.
