## ✨ Что добавлено в этом обновлении

### 🤖 Система многих провайдеров ИИ
- **Поддержка 8+ провайдеров**: Gemini, OpenAI, Anthropic Claude, DeepSeek, Qwen, GigaChat, OpenRouter, Custom API
- **Управление профилями**: Добавляйте, редактируйте, удаляйте провайдеры ИИ
- **Активный провайдер**: Выбирайте какой провайдер использовать для анализа
- **Безопасное хранение API ключей**: Ключи кодируются перед сохранением в браузере

### 👁️ Предварительный просмотр запроса
- **Перед отправкой к ИИ** появляется диалог с полным текстом запроса
- **Можно отредактировать** запрос прямо перед отправкой
- **Проверка конфиденциальности**: Удалите ФИО и контакты если не нужны
- **Безопасность данных**: Визуально проверяйте, что не отправляются лишние данные

### 🖨️ Функции печати
- **Печать консультации**: Красиво оформленный отчет с полными данными пациента
- **Печать ответа ИИ**: Сохраняйте результаты анализа ИИ в PDF
- **Оптимизировано для печати**: Удаляются ненужные элементы интерфейса

### 📂 Управление пациентами
- **Сохранение пациентов локально**: Работайте с разными пациентами
- **Импорт пациентов**: Загружайте раньше экспортированные консультации
- **История пациентов**: Просмотрите когда был сохранен каждый пациент

### 💾 Четкое разделение: Сохранить vs Экспорт

| Функция | Сохранить пациента | Экспорт в JSON |
|---------|-------------------|----------------|
| **Кнопка** | 💾 Сохранить | 💾 Экспорт в JSON |
| **Что делает** | Сохраняет в браузер | Скачивает файл на ПК |
| **Где хранится** | localStorage браузера | Файл на диске |
| **Использование** | Работа с историей пациентов | Резервная копия, обмен, архив |
| **Видимость** | Только в приложении | На компьютере пользователя |
| **GDPR** | Требует очистки браузера | Нужно вручную удалить файл |

## 🚀 Как начать работу

### 1. Откройте приложение
```bash
# Просто откройте в браузере
OncoAssistWeb.html
```

### 2. Добавьте провайдер ИИ (опционально)
- Нажмите **🤖 ИИ Настройки**
- Нажмите **➕ Добавить провайдер**
- Выберите тип (рекомендуется Google Gemini)
- Получите API ключ на сайте провайдера
- Заполните форму и нажмите добавить

### 3. Работайте с пациентом
- Заполните информацию о пациенте
- Добавьте анамнез, результаты осмотра и обследований
- Используйте **🤖 Анализ ИИ** на странице Диагноз

### 4. Сохраняйте и экспортируйте
- **💾 Сохранить**: Сохраняет пациента локально в браузер
- **💾 Экспорт в JSON**: Скачивает файл на ПК (для резервной копии)
- **🖨️ Печать**: Открывает для печати или сохранения в PDF

## 🔄 Процесс анализа ИИ

```
1. Пользователь нажимает "🧠 Анализ ИИ"
                          ↓
2. Приложение АВТОМАТИЧЕСКИ составляет промпт:
   - Информация о пациенте (возраст, пол, менопауза)
   - Жалобы и анамнез
   - Данные осмотра (ИМТ, давление, осмотр органов)
   - Лабораторные показатели
   - Инструментальные данные
                          ↓
3. ОТКРЫВАЕТСЯ ОКНО ПРЕДПРОСМОТРА:
   - Показывается полный текст запроса
   - Вы можете отредактировать (удалить ФИО и т.п.)
   - ⚠️ Предупреждение о конфиденциальности
                          ↓
4. Вы нажимаете "✉️ Отправить запрос"
   (или отменяете)
                          ↓
5. API ключ используется ДО ОТПРАВКИ:
   - Запрос + API ключ отправляются в ИИ
   - ИИ анализирует и отправляет ответ
   - Ответ приходит в приложение
                          ↓
6. ОТВЕТ СОХРАНЯЕТСЯ:
   - Ровно в консультацию пациента
   - В диагнозе (раздел "Рабочий диагноз")
   - Можно распечатать или экспортировать
```

## 📝 Примеры использования

### Пример 1: Диагностика рака молочной железы
1. Заполните данные пациентки 45 лет
2. Добавьте жалобы: "Уплотнение молочной железы"
3. Добавьте находки осмотра: "Уплотнение, площадь 2см"
4. Добавьте УЗИ результаты
5. Нажмите "🤖 Анализ ИИ"
6. Проверьте предпросмотр, нажмите "Отправить"
7. Получите дифференциальный диагноз
8. Сохраните пациента "💾 Сохранить"

### Пример 2: Встреча с коллегой
1. Работаете с новым пациентом
2. Заполняете все данные
3. Нажимаете "💾 Экспорт в JSON"
4. Отправляете файл коллеге по email
5. Коллега открывает приложение
6. Нажимает "📂 Загрузить пациента" → "Импортировать из файла"
7. Видит всю консультацию и может добавить свои рекомендации

### Пример 3: Архивирование пациента
1. Консультация завершена
2. Нажимаете "💾 Экспорт в JSON"
3. Файл сохраняется на защищенное хранилище (NAS, облако)
4. Через месяц нужны данные → "📂 Загрузить пациента"
5. Загружаете файл из архива

## 🆘 FAQ

**Q: Где хранятся мои данные?**  
A: В браузере локально. Никуда не отправляются без вашего разрешения.

**Q:安全ли отправлять данные ИИ?**  
A: Когда вы нажимаете "Отправить", данные отправляютсянапрямую в выбранный ИИ сервис (Gemini, OpenAI, и т.д.). Проверьте их политику конфиденциальности.

**Q: Могу ли я использовать это в больнице?**  
A: Да, но убедитесь что соответствуете требованиям HIPAA/GDPR. Используйте Enterprise API провайдеров.

**Q: Почему нет сервера/БД?**  
A: 1) Иньше (все в браузере), 2) Безопаснее (данные не на сервере), 3) Быстрее (нет задержек сети), 4) Приватнее (ваши данные остаются у вас)

**Q: Как удалить все данные?**  
A: Кнопка "🗑️ Очистить" удалит текущую консультацию, или очистите кэш браузера (Settings → Privacy → Clear browsing data).

**Q: Какой ИИ выбрать?**  
A: Начните с Google Gemini (FREE! 60 req/min). Потом попробуйте OpenAI если нужна большая мощность.
