# OncoAssist Web - Справка по безопасности и функциям

## 🔒 Безопасность и конфиденциальность

### Общие принципы безопасности

1. **Локальное хранилище данных**: Все данные пациентов и API ключи хранятся локально в браузере (localStorage), НЕ отправляются на внешние серверы
2. **API ключи зашифрованы**: API ключи кодируются перед сохранением (base64 - для браузера, в производстве используйте proper encryption)
3. **Нет отслеживания**: Приложение не собирает телеметрию или аналитику
4. **Открытый исходный код**: Весь код находится в браузере и может быть проверен

### Защита конфиденциальной информации

#### При отправке запроса к ИИ:
- ✅ **Перед отправкой** показывается диалог предварительного просмотра
- ✅ **Вы можете отредактировать** запрос перед отправкой
- ✅ **Можно удалить** чувствительные данные (ФИО, контакты)
- ✅ **API ключ отправляется прямо в ИИ**, не проходит через промежуточные серверы

#### Рекомендации:
- ⚠️ **Никогда не делитесь API ключами**
- ⚠️ **Проверяйте запрос перед отправкой** на наличие ФИО и прямых контактов
- ⚠️ **Используйте VPN/HTTPS** для защиты при работе на публичных сетях
- ⚠️ **Регулярно очищайте кэш браузера** если делитесь компьютером

### Защита данных пациентов в браузере

```
В localStorage хранится:
├── onco_consultation_data (текущая консультация) - в открытом виде
├── onco_saved_patients (сохраненные пациенты) - в открытом виде
├── onco_ai_providers (профили ИИ) - API ключи в базовой кодировке
└── ai_settings_enhanced (дополнительные настройки ИИ)
```

**Для продакшена рекомендуется:**
- Использовать proper AES-256 шифрование
- Добавить PIN/пароль защиту при запуске
- Использовать IndexedDB вместо localStorage
- Реализовать автоматическое стирание данных через 24 часа

## 📊 Функции управления данными

### 1. **Сохранить пациента** (💾 Сохранить)
**Что делает:** Сохраняет текущего пациента в локальное хранилище браузера

- Сохраняет ВСЕ данные консультации (пациент, анамнез, осмотр, диагноз и т.д.)
- Хранится локально (в браузере)
- Можно загрузить их позже
- Можно работать с несколькими пациентами
- Данные НЕ отправляются никуда

**Где:** Кнопка "💾 Сохранить" → выбрать пациента → сохранить локально

**Как загрузить:** Кнопка "📂 Загрузить пациента" → выбрать из списка

### 2. **Экспорт консультации** (💾 Экспорт в JSON)
**Что делает:** Скачивает консультацию в виде JSON-файла на компьютер

- Создает файл `consultation_ИМЯ_ДАТА.json`
- Содержит ВСЕ данные в машиночитаемом формате
- Можно использовать для:
  - Резервной копии
  - Обмена с коллегами
  - Импорта в другие системы/БД
  - Архивирования

**Где:** Кнопка "💾 Экспорт в JSON" → файл скачивается

**Как использовать:** Кнопка "📂 Загрузить пациента" → "Импортировать из файла"

### 3. **Печать консультации** (🖨️ Печать)
**Что делает:** Открывает красиво оформленный отчет для печати или сохранения в PDF

- Форматирует все данные консультации
- Включает информацию о пациенте, жалобы, результаты осмотра, диагноз, лечение
- Оптимизирован для печати
- Можно сохранить как PDF в браузере

**Где:** Кнопка "🖨️ Печать"

### Сравнение: Сохранить vs Экспорт

```
┌─────────────────────┬──────────────────────┬──────────────────┐
│ Операция            │ Сохранить            │ Экспорт          │
├─────────────────────┼──────────────────────┼──────────────────┤
│ Где хранится        │ В браузере (локально)│ На компьютере    │
│ Видимость           │ Только в приложении  │ Видна в файлах   │
│ Безопасность        │ Если браузер очищен  │ Остается на ПК   │
│ Обмен данными       │ Нет                  │ Да - через файл  │
│ Резервная копия     │ Нет                  │ Да               │
│ Удатение            │ Если очистить кэш    │ Нужно удалить    │
│ Форматирование      │ Структурированно     │ JSON             │
└─────────────────────┴──────────────────────┴──────────────────┘
```

## 🤖 ИИ-анализ и провайдеры

### Поддерживаемые провайдеры

1. **Google Gemini** ⭐ Рекомендуется
   - Бесплатный API ключ на https://ai.google.dev
   - Хорошая поддержка изображений
   - Быстрый и точный

2. **OpenAI (ChatGPT)**
   - Требует API ключ: https://platform.openai.com
   - Платный (но качественный)
   - Модель: gpt-4-turbo

3. **Anthropic (Claude)**
   - API ключ: https://console.anthropic.com
   - Платный
   - Отлично работает с документами

4. **DeepSeek, Qwen, GigaChat и другие**
   - Региональные альтернативы
   - Требуют учетные записи

### Как добавить провайдер ИИ

1. Кнопка "🤖 ИИ Настройки"
2. "Добавить новый провайдер"
3. Выбрать тип (Gemini, OpenAI, и т.д.)
4. Заполнить:
   - **Имя профиля**: Произвольное имя для вашей системы
   - **API Ключ**: Получить на сайте провайдера
   - **Base URL**: Обычно автоматический, переопределить для custom API
   - **Модель**: Имя модели (напр. gpt-4-turbo)
5. Нажать "➕ Добавить провайдер"

### Работа с ИИ-анализом

1. Перейти на страницу "Диагноз"
2. Заполнить все необходимые данные (пациент, анамнез, осмотр, обследования)
3. Нажать "🧠 Анализ ИИ"
4. **Появится диалог предварительного просмотра:**
   - Проверить запрос
   - Удалить чувствительные данные если нужно
   - Нажать "✉️ Отправить запрос"
5. Получить ответ от ИИ в отдельном окне
6. Ответ сохраняется в консультации
7. Можно распечатать или экспортировать

### ⚠️ Важные замечания о конфиденциальности

- **API ключ отправляется напрямую от вас к ИИ сервису** (не через промежуточные серверы)
- **Проверяйте запрос перед отправкой** - удаляйте ФИО, контакты если не требуются
- **ИИ-анализ - вспомогательный инструмент**, финальное решение - за врачом
- **Для HIPAA-compliant** систем используйте Enterprise версию провайдеров

## 📱 Импорт и экспорт пациентов

### Импорт пациента из файла

1. Кнопка "📂 Загрузить пациента"
2. Сверху форма "Импортировать из файла"
3. Выбрать JSON файл консультации
4. Данные пациента загружаются в приложение

### Экспорт для коллег

1. Заполнить консультацию полностью
2. "💾 Экспорт в JSON"
3. Отправить файл коллеге по email или файлообменнику
4. Коллега может загрузить через "📂 Загрузить пациента"

## 🆘 Решение проблем

### "ИИ не работает"
- Проверьте, что провайдер активирован (зелёный статус в ИИ Настройки)
- Проверьте, что API ключ введен и не пустой
- Проверьте соединение с интернетом
- Проверьте, что еще не исчерпан лимит API запросов

### "Данные не сохраняются"
- Проверьте, что localStorage не отключён в браузере
- Попробуйте очистить кэш браузера и перезагрузиться
- Используйте другой браузер для теста

### "Не могу загрузить пациента"
- Убедитесь, что файл в формате JSON
- Проверьте, что файл не повреждён
- Попробуйте экспортировать и переимпортировать
