# Changelog - OncoAssist Web v2.0

## Версия 2.0 - MAJOR UPDATE (Март 2026)

### ✨ Новые возможности

#### 🤖 Система управления провайдерами ИИ
- Добавлена поддержка 8+ провайдеров ИИ:
  - Google Gemini
  - OpenAI (ChatGPT, GPT-4)
  - Anthropic Claude
  - DeepSeek
  - Alibaba Qwen
  - Sberbank GigaChat
  - OpenRouter
  - Custom API endpoints
- Одновременно можно создать несколько профилей провайдеров
- Переключение между активными провайдерами
- Управление API ключами (добавление, редактирование, удаление)

#### 👁️ Диалог предварительного просмотра запроса
- Перед отправкой к ИИ показывается полный текст запроса
- Возможность редактирования запроса прямо в диалоге
- Удаление конфиденциальной информации (ФИО, контакты)
- Визуальное подтверждение перед отправкой
- Выбор провайдера прямо из диалога

#### 🖨️ Функции печати и экспорта
- Печать полной консультации (красивый отчет)
- Печать ответа ИИ отдельно
- Оптимизированный для печати формат
- Сохранение в PDF через браузер
- Экспорт в JSON для резервной копии

#### 📂 Управление пациентами
- Сохранение пациентов в локальное хранилище
- Загрузка раньше сохраненных пациентов
- Импорт пациентов из JSON файлов
- Просмотр списка всех сохраненных пациентов с датой
- Удаление пациентов из архива

#### 🔒 Улучшенная безопасность
- ⚠️ Предупреждение о конфиденциальности при отправке запроса
- Шифрование API ключей перед сохранением
- Четкое разделение между локальным хранилищем и отправкой
- Рекомендации по безопасности для пользователей
- Документация по HIPAA/GDPR compliance

### 📝 Изменения в функциональности

#### Заголовок приложения
- Новое меню действий с 5 кнопками:
  - 📂 Загрузить пациента (вместо "Загрузить")
  - 💾 Экспорт в JSON (вместо "Экспорт")
  - 🖨️ Печать (новая)
  - 🤖 ИИ Настройки (новая)
  - 🗑️ Очистить

#### Страница "Диагноз"
- Добавлено предупреждение о конфиденциальности ИИ
- Кнопка "🧠 Анализ ИИ" открывает диалог предпросмотра
- Сохранение ответов ИИ в консультацию
- Информация о провайдере и времени анализа

#### Модальные окна (новые)
1. **ИИ Настройки** - управление провайдерами
2. **Предварительный просмотр** - редактирование запроса
3. **Загрузить пациента** - импорт и выбор из архива
4. **Ответ ИИ** - просмотр результатов с опциями печати

### 🔧 Технические улучшения

#### Новые функции JavaScript:
```javascript
// Управление провайдерами

// Модальные окна
```

#### Новые данные в localStorage:
- `onco_ai_providers` - профили провайдеров с закодированными ключами
- `onco_saved_patients` - архив всех сохраненных пациентов
- `ai_settings_enhanced` - дополнительные настройки ИИ

### 📊 Документация

Добавлены новые файлы:
- `OncoAssistWeb_README.md` - полная инструкция пользователя
- `OncoAssistWeb_SECURITY_AND_FEATURES.md` - детальная документация по безопасности

### 🐛 Исправления

- Полностью переработан интерфейс (более модульный и чистый)
- Лучше отображение на мобильных устройствах
- Улучшена обработка ошибок
- Более информативные сообщения пользователю

### ⚠️ BREAKING CHANGES

- Кнопка "Сохранить" переименована в "💾 Сохранить" (функционально тот же)
- Кнопка "Экспорт" переименована в "💾 Экспорт в JSON" (функционально тот же)
- Функция `generateDiagnosis()` теперь требует настроенного провайдера ИИ

### 📈 Производительность

- Добавлено ленивое кэширование провайдеров
- Оптимизирована рендеринг списка пациентов
- При открытии модалей локальный поиск по пациентам

### 🔐 Безопасность

- API ключи кодируются перед сохранением (base64 в браузере)
- Для production рекомендуется использовать AES-256
- Добавлены предупреждения на критичных местах
- Рекомендации по HIPAA/GDPR compliance
