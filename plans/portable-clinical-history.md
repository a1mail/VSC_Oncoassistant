# План: клиническая история и Diagassist 6

Package Manager: npm (package-lock.json)
Framework: React + Vite
Status: Verification complete; commit/push pending

## Цель
Сохранить существующие функции, добавить датированную историю заболевания,
повторные обследования, свободные поля и вставку документов; изолировать
постоянное хранение данных в standalone от браузера чужого компьютера.

## Согласованные решения
- `history` хранит дату, полный текст, редактируемое краткое резюме, диагноз,
  назначенное и проведенное лечение отдельно. Отчет содержит только краткую
  историю, ИИ получает полные записи. Отсутствующие даты не выдумываются.
- `imaging_studies` хранит повторные исследования; старые поля остаются
  совместимыми и отображаются как исходная запись без даты.
- Общий режим молочных желез исключает раздельные сведения только из
  отчета и контекста ИИ, но не удаляет сохраненные данные.
- До 10 вставленных текстовых документов; загрузка файлов не ограничивается
  новым лимитом. Редактирование и флаг анализа сохраняются.
- Portable использует память вместо localStorage для всех ключей приложения.
  До выбора папки сохранение в базу завершается явной ошибкой, а введенные
  данные остаются в памяти. Завершение сеанса запрещено во время ИИ-запроса.
- JSON записывается последовательно; предыдущая версия хранится в резервном
  файле на том же носителе. Ошибка записи передается интерфейсу.
- Старые HTML остаются неизменными. Новый файл: `HTML variant/Diagassist_6.html`.
  HTML собирается без ключей окружения и персональных данных.

от копирования на чужом компьютере. Приватность репозитория не меняется.
