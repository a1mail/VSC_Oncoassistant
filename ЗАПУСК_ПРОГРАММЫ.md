# 🚀 OncoAssistant - Быстрый старт

## Запуск программы

### **Способ 1: Двойной клик (Самый простой) ⭐**
1. Откройте папку проекта: `c:\Users\a1mai\Downloads\oncoassistant_Tai\`
2. Дважды кликните на файл: **`start-oncoassistant.bat`**
3. Программа запустится автоматически в браузере на **http://localhost:3000**

### **Способ 2: PowerShell**
```powershell
# Откройте PowerShell в папке проекта и запустите:
.\start-oncoassistant.ps1
```

### **Способ 3: Командная строка**
```bash
npm install   # Только первый раз
npm run dev
```

## ⚠️ Первый запуск

**При первом клике на батник:**
1. Создастся **новое окно консоли** (так лучше видны ошибки)
2. Загрузятся зависимости npm (~2-5 минут)
3. Откроется браузер на http://localhost:3000

---

## 🔑 Получение API ключа (Важно!)

Программа использует **Google Gemini API** для анализа данных.

### Шаги:
1. Откройте: https://aistudio.google.com/app/apikeys
2. Кликните **"Create API Key"**
3. Скопируйте ключ
4. Откройте файл `.env` в папке проекта
5. Замените строку:
   ```
   API_KEY="AIzaSyDummyKeyExample123456789"
   ```
   На вашу строку:
   ```
   API_KEY="AIzaSy_ВАШ_ДЛИННЫЙ_КЛЮЧ_ЗДЕСЬ"
   ```
6. Сохраните файл (Ctrl+S)
7. Перезагрузите браузер или перезапустите батник

## 🐛 Если не работает?

### Батник закрывается моментально
- Проверьте установлен ли **Node.js 20+**
  - Скачайте: https://nodejs.org/ (LTS версия)
  - После установки перезагрузитесь

### Chrome/Edge говорит "Не удается подключиться"
- Дождитесь, пока консоль выведет "Сервер запущен"
- Попробуйте обновить страницу (F5)
- Закройте браузер и перезапустите батник

### Ошибка "Порт 3000 уже используется"
- Откройте диспетчер задач (Ctrl+Shift+Esc)
- Найдите "Node.js" или "node"
- Нажмите "Завершить"
- Перезапустите батник

### Ошибка API ключа
- Проверьте, что `.env` файл создан
- Убедитесь, что API_KEY не пуст
- Получите новый ключ на https://aistudio.google.com/app/apikeys
