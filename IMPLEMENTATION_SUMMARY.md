### 5️⃣ Разделение "Сохранить" vs "Экспорт" (✓ ЗАВЕРШЕНО)

**Четкое разделение двух операций:**

| Функция | Кнопка | Действие | Хранилище | Использование |
|---------|--------|---------|-----------|--------------|
| **Сохранить пациента** | 💾 Сохранить | Пациент сохраняется в браузер | localStorage | Работа с историей пациентов |
| **Экспорт в JSON** | 💾 Экспорт | Консультация скачивается файлом | На диске | Резервная копия, обмен, архив |

**Функции:**
```javascript
saveCurrentPatient()    // Сохранить в браузер
exportConsultation()    // Скачать JSON файл
```

## 🎯 ОТВЕТЫ НА ВОПРОСЫ

### Q: Разница между "Сохранить" и "Экспорт"?
**A:** 
- **Сохранить** → сохраняет в браузер (localStorage)
- **Экспорт** → скачивает JSON файл на диск
- Подробнее в `OncoAssistWeb_README.md`

### Q: Как работает ИИ?
**A:**
1. Вы нажимаете "🧠 Анализ ИИ"
2. Появляется диалог предпросмотра с запросом
3. Вы можете отредактировать или удалить данные
4. Нажимаете "✉️ Отправить"
5. API ключ + запрос отправляются в выбранный ИИ
6. Ответ приходит в приложение и сохраняется

### Q: Безопасно ли отправлять данные ИИ?
**A:**
- ✅ Данные отправляются НАПРЯМУЮ в выбранный ИИ
- ✅ Не проходят через промежуточные серверы
- ✅ Вы видите ВСЕ данные перед отправкой
- ✅ Можно удалить чувствительные данные
- ⚠️ Но помните: ИИ сервисы могут логировать запросы
- ⚠️ Для HIPAA используйте Enterprise API

### Q: Как добавить свой ИИ провайдер?
**A:**
1. 🤖 ИИ Настройки
2. ➕ Добавить провайдер
3. Выбрать тип или Custom API
4. Заполнить API ключ и Base URL
5. Нажать добавить
- Подробнее в `QUICKSTART.md`

### Q: Какой ИИ выбрать?
**A:**
- **Бесплатный**: Google Gemini (рекомендуется для теста)
- **Мощный**: OpenAI GPT-4 (платно)
- **Баланс**: Anthropic Claude (платно)
- Ключи легко переключать через 🤖 ИИ Настройки

### Q: Как импортировать пациента?
**A:**
1. 📂 Загрузить пациента
2. Выбрать из сохраненных ИЛИ
3. "Импортировать из файла" → выбрать JSON
- Подробнее в `OncoAssistWeb_README.md`

## 📞 ТЕХНИЧЕСКАЯ ПОДДЕРЖКА

### Если что-то не работает:
1. Откройте консоль браузера (F12)
2. Скопируйте сообщение об ошибке
3. Отправьте разработчикам

### Основные ошибки и решения:
- **"ИИ не отвечает"**: Проверьте интернет и API ключ
- **"401 Unauthorized"**: Ключ неправильный, обновите
- **"Данные не сохраняются"**: Очистите кэш браузера
- **"Файл не импортируется"**: Убедитесь это JSON
